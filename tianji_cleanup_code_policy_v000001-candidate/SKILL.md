# 杯子投入垃圾桶流程

## 运行约束

- 观测：仅 `head`、`left_wrist`、`right_wrist` RGB；可用静态 URDF/相机标定和自己的指令历史。
- 控制：16 维绝对动作，左臂执行，右臂 8 个通道必须等于初始动作；底盘固定。
- 禁止运行期读取仿真真值、深度、接触、编码器或调用 VLA/LLM。

## 技能顺序

1. 从 head 图像用吸管绿色连通域锚定目标，并拟合杯盖轮廓求杯身 XY；若轮廓证据不足即停止。
2. 观察桶口 wrist RGB，以暗色内区和亮色环形边缘搜索桶中心；再用圆环拟合复核。未找到可支持的桶口时，不搬运。
3. 使用侧向接近杯身，不从杯盖上方套取。保留预接近、低速水平进入和闭合期间的杯体移动检查；杯体明显移动时中止。
4. 按已校准夹爪闭合曲线补偿接触引起的末端轴向位移；抬高约 0.15 m。用 RGB 杯盖尺度变化确认杯子已抬起，证据不足不得运输。
5. 搬运先沿桌外侧退出，再平滑转到桶中心；在桶外降到释放高度后完全开爪，向外上方撤离并等待稳定。
