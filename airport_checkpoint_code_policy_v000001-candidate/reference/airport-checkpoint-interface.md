# Checkpoint 控制与传感接口契约

本契约对接当前 Isaac Sim 机器人，供后续真机适配参考。真机型号、驱动和标定未确定，
不阻塞仿真开发；当前没有已验证的真机 transport 或停车性能。
类型定义以 [`types.py`](../airport/checkpoint/types.py) 和
[`sensors.py`](../airport/checkpoint/sensors.py) 为准，执行边界见
[`deployment.py`](../airport/checkpoint/deployment.py)。

## 坐标、单位与机器人

- 所有位置、点云和表面片使用同一经过标定的固定工作坐标系，单位 m；不能混入相机或 EEF 局部坐标。
- `base_pose` 为 `(x,y,z,yaw)`；关节角和 EEF 的 `xyz` 固定轴欧拉角使用 rad。
  时间戳使用同一单调时钟的秒值，`sequence` 随物理测量推进。
- 相机光学轴为 X 向右、Y 向下、Z 向前；`optical_to_work` 是齐次刚体变换。
  当前相机安装是假设的 `sens_link` 固定安装，不是硬件标定结果。
- RGB-D 的 `pixel_offset_xy` 是采样标定字段；旧记录默认 `(0,0)`，不能静默重解释。
  新的受控仿真候选使用实测支持的 `(0.5,0.5)`，须与自身深度射线使用同一约定。
- 当前固定底座 IK 仅使用 `motion.names` 的 11 个折叠腰/躯干和右臂关节。
  不发送底座平移、转动或轮命令；头部、左臂、夹爪不参与该 IK，夹爪由独立 `grip` 控制。
  关节名称、零位、方向和限位以当前 URDF 与适配器映射为依据。

## Backend 方法

| 方法 | 必须满足的行为 |
| --- | --- |
| `observe()` | 返回新测量及来源；缺失数据显式为不可用，不能补入场景真值或旧值冒充新值。 |
| `check_reachability(action)` | 只读检查固定底座下的 IK、整条路径、人体/障碍和工具包络；拒绝时不得执行动作。 |
| `execute(action)` | 移动必须对应同一物理时刻刚通过的规划；物理推进或新观测使旧规划失效。执行期间保持低层监控。 |
| `stop(reason)` | 进入适配器的停机流程并记录原因；真实停机延迟和残余运动必须另行测量。 |

`hold` 保持既有目标。仿真专用 `hold_pose` 是独立操作：仅允许同一测量时刻被拒的、
未持纸 `PICK_APPROACH`，将上述 11 个关节的目标重设为当前编码器值并清除规划缓存。
它保留物理速度、PD、重力前馈和逐步监控，随后推进 50ms；不允许 teleport、清零速度或重标力零点。
连续拒绝最多重测两次，第三次停止；每次重测仍检查旅客、纸张、力及新传感时间戳。
真机模式不使用该重检，原生制动探针的通过也不构成真机停车认证。

## 输入与缺测处理

`Observation` 包含编码器、自己的底座姿态、EEF FK、旅客跟踪、实测表面片和纸张可见端点。
`paper_visible_length_m` 只表示观测到的长度，不能代入隐藏纸长。人体方向未知时保持未知，
不能用场景设置的 yaw 代替测量。表面片必须保留置信度和测量时刻。

每个必需通道（`rgbd`、`joints`、`gripper`、`force`）带 `SensorProvenance`。
仿真标为 `synthetic`；真机不得将其改名为 `measured` 来绕过检查。
夹爪开度单位 m、力单位 N。腕部反力使用重力/载荷/零偏补偿后的 50ms 动量窗口，
保留窗口起止及中点时间；`wrist_force_n` 是向量范数，不能当作有符号法向力。
窗口尚未填满或补偿不可用时返回 `None`，不以零替代。

新候选的 `RenderSynchrony` 绑定实际渲染帧号、渲染/world 时间、编码器序号和时间，
以及编码器、相机标定、同步探针的哈希。world 时钟与策略的 `step*dt` 存在初始化原点差，
分别保留原始值，不能直接混用。仅有 ReferenceTime 不能证明几何同步。
当前固定镜像的 `zero_delay_v1` 已有独立原生运动探针依据，完整策略接线仍需验证。
自身深度过滤使用经验容差；缺同步、标定或帧健康检查失败时保留未知点。
查询模型包括实际渲染的两块指尖垫。射线未命中或沿光轴深度不一致的点，只有取得
距当前自身真实三角表面不超过 20µm 的证据，才能成为额外的 `surface_candidate`。
这里采用三维 Euclidean 距离，不能据此声称所有光轴方向近移点都保留。
未取得证据的点、纸张与受跟踪支持的人体点保留；两类误差带内仍可能有真实前景，
仿真中的候选过滤不能作为真机安全认证。

`PolicyConfig` 的当前默认值包括：测量最大年龄 0.25s、底座位移容差 2mm、yaw 容差 0.01rad，
运输/采样速度 0.10/0.02m/s，以及接触力窗口 0.0005–1.5N（目标 0.001N）。
这些是当前实验参数，非真机能力证明；冻结候选的参数和固定评估协议才是该次运行依据。
真机若需要不同范围，应单独标定并版本化协议，不能静默修改本实验的成功阈值。

## 部署与证据

冻结策略入口 `run_policy` 不调用 LLM、VLA 或轨迹回放。真实模式要求
`DeploymentEvidence` 的接口、标定、固定底座、碰撞、停车、力补偿、工具对齐和感知验证引用。
当前实现只检查引用字段非空；引用本身仍须由未来具体适配器核验，不能作为安全认证。

场景真值、actor ID、物体 USD 位姿及原生成功判定只进入独立审计链，不充当机器人测量。
每次实验保存绑定、源码/场景/协议哈希、传感时序、动作、拒绝规划、primitive 瞬态、违规及视频。
当前完整三人任务尚未通过；版本状态见[实验说明](airport-checkpoint-experiment.md)。
